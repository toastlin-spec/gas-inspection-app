# 加油站自主檢查巡檢 App

讓北區、中區、南區共 71 個加油站以手機完成自主檢查與安保專員 SL-H015 查核，異常即時通報並追蹤到改善結案，取代紙本檢查表。

## 技術架構

- 後端：Google Apps Script（`Code.gs`）
- 前端：`Index.html`，Tailwind CSS + DaisyUI + Lucide Icons，手機直式畫面為主
- 資料：Google 試算表（站點、人員、檢查項目、檢查紀錄、檢查明細、異常追蹤、設定）
- 照片：Google 雲端硬碟
- 通知：Gmail，由每日排程觸發器寄送

## 資料夾結構

| 路徑 | 內容 |

| `docs/SL-H015查核項目.md` | 公司 SL-H015 加油站安全衛生管理及營運設備查核表（0601 版）42 項清單與項目代碼 |

## 檢查表

| 表單 | 填寫人 | 頻率 | 計分 |
| --- | --- | --- | --- |
| 站內自主檢查（12 項） | 站長 | 每日、每週、每月 | 正常／異常／不適用，不計分 |
| SL-H015 安保專員查核（42 項＋4 個其他欄位） | 安保專員 | 每站每季一次（暫定） | 不適用項目扣除後換算百分制 |

不符合或異常項目依風險等級設定改善期限：高 1 天、中 3 天、低 7 天。SL-H015 項目的風險等級依配分決定（3 分以上高、2 分中、1 分低）。

## 開發階段

1. 每日檢查上線：登入、首頁、填寫檢查、拍照上傳、管理設定（已完成）
2. 異常追蹤：異常清單、詳情、改善回報、驗證結案、高風險即時通知
3. 週檢、月檢、SL-H015 查核表與排程通知、區域總覽
4. 報表與全面推廣
