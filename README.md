# 加油站自主檢查巡檢 App

讓北區、中區、南區共 71 個加油站以手機完成自主檢查、安保專員 SL-H015 查核與營運設備現場重點項目檢查，異常即時通報並追蹤到改善結案，取代紙本檢查表。

## 技術架構

- 後端：Google Apps Script（`Code.gs`）
- 前端：`Index.html`，單一檔案（自訂樣式，不依賴外部框架），手機直式畫面為主
- 資料：Google 試算表（站點、人員、檢查項目、檢查紀錄、檢查明細、異常追蹤、設定）
- 照片：Google 雲端硬碟
- 通知：Gmail，由每日排程觸發器寄送

## 角色

| 角色 | 登入密碼（試算表「設定」） | 人員資料 | 可以做的事 |
| --- | --- | --- | --- |
| 站長 | `登入密碼_站長` | 「站點」的站長欄 | 自主檢查、自己站的營運設備檢查、看自己站的異常 |
| 安保專員 | `登入密碼_安保專員` | 「人員」角色＝安保專員 | SL-H015 查核、負責區域的營運設備檢查、看異常 |
| 油品主管 | `登入密碼_油品主管` | 「人員」角色含「主管」或「經理」（例如油品主管），負責區域填北區／中區／南區或全區，啟用空白視為啟用 | 唯讀：負責區域的總覽、缺失（異常）、匯出查核與設備檢查 Excel |
| 系統管理員 | `登入密碼_系統管理員` | — | 管理設定、資料檢查 |

## 檢查表

| 表單 | 填寫人 | 頻率 | 計分 |
| --- | --- | --- | --- |
| 站內自主檢查（12 項） | 站長 | 每日、每週、每月 | 正常／異常／不適用，不計分 |
| SL-H015 安保專員查核（42 項＋4 個其他欄位） | 安保專員 | 每站每季一次（暫定） | 不適用項目扣除後換算百分制 |
| 營運設備現場重點項目檢查（12 類 82 項） | 站長（自己的站）或安保專員（負責區域） | 不定期 | 良好／不良／無此設備，不計分 |

不符合或異常項目依風險等級設定改善期限：高 1 天、中 3 天、低 7 天。SL-H015 項目的風險等級依配分決定（3 分以上高、2 分中、1 分低）。營運設備檢查項目的風險等級為系統預設值，可在試算表「檢查項目」調整。

營運設備檢查的項目在第一次使用時自動寫入試算表「檢查項目」（表單類型「營運設備檢查表」），不需要手動匯入。

## 開發階段

1. 每日檢查上線：登入、首頁、填寫檢查、拍照上傳、管理設定（已完成）
2. 異常追蹤：異常清單、詳情、改善回報、驗證結案、高風險即時通知
3. 週檢、月檢、SL-H015 查核表與排程通知、區域總覽（SL-H015 查核與匯出 Excel 已提前完成）
4. 報表與全面推廣
